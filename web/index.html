PDF →to KiCad

Reconstructs an editable KiCad project from a schematic PDF.

Conversion runs entirely in this browser tab. Your file is not uploaded anywhere.

  • Works with vector schematic PDFs printed from OrCAD Capture or Altium Designer.
  • Does not work with scanned or image-only PDFs, PCB layout plots, or PDFs from other tools.
  • The result is rebuilt from the PDF’s drawing strokes and text, so check it in KiCad before relying on it.

Drop a schematic .pdf here

or a .zip archive containing exactly one. You can also paste a copied file.
